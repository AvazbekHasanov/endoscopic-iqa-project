HOW TO USE
================================================================================

Step 1: Install dependencies
$ pip install psycopg2-binary python-docx pandas matplotlib seaborn scipy scikit-learn

Step 2: Try the demo (no database required)
$ python3 evaluation/demo_results_analysis.py

Step 3: Configure database (edit scripts/db_config.py)
DB_CONFIG = {
    'host': 'localhost',
    'port': 5432,
    'database': 'postgres',
    'user': 'your_username',
    'password': 'your_password'
}

Step 4: Run full analysis
$ python3 evaluation/results_analysis_v2.py

Step 5: Open the Word document
results_analysis_v2/Comprehensive_Results_Analysis.docx
